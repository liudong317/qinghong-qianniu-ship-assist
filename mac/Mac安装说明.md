晴红千牛发货助手 · Mac 安装说明

本软件为 Apple Silicon（M1 / M2 / M3 / M4） 版本，双击 `晴红千牛发货助手.app` 即可使用。

若提示「无法打开，因为无法验证开发者」或「已损坏」，按下面任一种方式处理即可。

方法一：右键打开（推荐，最简单）

1. 在访达中找到 `晴红千牛发货助手.app`
2. 按住 Control 键点击（或右键点击）应用图标
3. 选择 「打开」
4. 在弹出对话框中再次点 「打开」

之后再双击即可正常启动。

方法二：系统设置里允许

1. 先双击一次应用（被拦下没关系）
2. 打开 系统设置 → 隐私与安全性
3. 往下找到「已阻止使用…」相关提示
4. 点击 「仍要打开」 / 「允许」

方法三：终端去掉隔离标记（仍打不开时）

1. 打开「终端」
2. 把下面命令里的路径改成你电脑上 `.app` 的实际位置，然后回车执行：

```bash
xattr -cr "/路径/到/晴红千牛发货助手.app"
```

例如应用在下载文件夹时：

```bash
xattr -cr ~/Downloads/晴红千牛发货助手.app
```

执行后再双击打开。
