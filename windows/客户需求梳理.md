## 一、客户是谁、要解决什么问题

**客户画像：** 使用千牛（淘宝/天猫卖家工具）进行批量发货的 Win 系统商户。

**核心痛点：** 收货信息经常以**一整段乱序文字**形式出现（聊天复制、订单截图打字等），手动拆成「收件人、手机号、地址」再填入 Excel 费时且易错。

**期望结果：** 粘贴文字 → 自动生成符合千牛导入格式的 Excel 表格；命中自定义关键词的记录**整行标红**，便于一眼识别特殊地址。

## 三、输入输出规格

### 3.1 输入

**形式：** 文本框批量粘贴

**单条样本示例：**

```
蔺玉泉[9196]15781066479天津市天津市河东区富民路街道月牙河南路与娄山道交叉路口往北约100米金月湾花园7号楼603[9196]
```

```
四川省广安市广安区 中桥街道四川省广安市广安区金安大道三段299号华冠城1701，漆洪兰，13541869970
```

**分隔规则：** 多条记录之间以**空行**分隔（或支持可配置分隔符）

### 3.2 输出

**文件格式：** `.xlsx`

**表头（与模板一致）：**

| 列 | 字段 |
|----|------|
| A | 收件人(必填) |
| B | 手机号(必填) |
| C | 收货地址(必填) |
| D | 平台订单号（非必填） |
| E | 商品信息(非必填) |
| F | 规格信息(非必填) |
| G | 商品数量(非必填) |
| H | 重量kg(非必填) |
| I | 备注(非必填) |

**期望解析结果示例：**

| 收件人 | 手机号 | 收货地址 |
|--------|--------|----------|
| 蔺玉泉[9196] | 15781066479 | 天津市天津市河东区富民路街道月牙河南路与娄山道交叉路口往北约100米金月湾花园7号楼603[9196] |
| 漆洪兰 | 13541869970 | 四川省广安市广安区 中桥街道四川省广安市广安区金安大道三段299号华冠城1701 |

### 3.3 关键词标记输出（整行标红）

**硬性要求：** 只要命中任一自定义关键词，该行必须**整行标红**，不能只标某一列或某一格。

**界面预览：** 命中行所有列（收件人、手机号、地址等）统一浅红背景 `#FFCCCC`；可选在标记列额外显示命中词标签（如 `驿站`）

**Excel 导出：** 命中行 **A~I 全列** 单元格均填充浅红色 `#FFCCCC`，保证打开文件后整行可见红色

**默认关键词：**

- 驿站
- 工商局
- 质检局

**客户自定义示例：** 快递柜、代收点、自提、学校、监狱 等

## 四、解析规则（客户侧应知晓）

### 4.1 支持的文本模式（已知）

1. **紧凑式：** `姓名[编号] + 11位手机号 + 地址[编号]`
2. **逗号倒序式：** `地址，姓名，手机号`
3. **标准式：** 已是三列 TSV/空格分隔（若未来扩展）

### 4.2 特殊规则

- 手机号：识别 11 位 `1` 开头的中国大陆号码
- `[四位数字]`：作为平台标识保留，不 stripping
- 解析失败：该行标黄提示「待人工处理」，不静默丢弃

### 4.3 AI 兜底（若启用晴红AI）

- 触发条件：规则引擎 confidence 低或字段缺失
- 输出格式：固定 JSON `{ "name", "phone", "address" }`
- 客户无感知，仅看到「AI 已优化」提示（可选）

## 五、关键词功能详细需求

### 5.1 管理界面

| 功能 | 要求 |
|------|------|
| 添加关键词 | 输入框 + 添加按钮，去重 |
| 删除关键词 | 点击标签 × 删除 |
| 默认词库 | 驿站、工商局、质检局 |
| 持久化 | 关闭再打开仍保留（本地存储或配置文件） |
| 空关键词 | 不允许添加 |

### 5.2 匹配规则

| 项 | 规则 |
|----|------|
| 算法 | 包含匹配（关键词出现在字段文本中即命中） |
| 扫描字段 | 收件人 + 收货地址 + 备注（默认）；**不扫描手机号** |
| 多词命中 | 全部展示，如 `驿站` `工商局` |
| 实时性 | 关键词变更后，预览表立即重新标红 |

### 5.3 展示规则（整行标红）

| 场景 | 表现 |
|------|------|
| 预览表命中 | **整行**背景 `#FFCCCC`（所有可见列）；标记列可附加红色 badge 显示命中词 |
| 预览表未命中 | 整行正常白底 |
| Excel 导出命中 | **A~I 全列**填充浅红色 `#FFCCCC`，整行标红 |
| Excel 导出未命中 | 整行无填充，保持默认白底 |

### 5.4 典型验收用例

| 原始地址片段 | 关键词 | 是否整行标红 |
|--------------|--------|--------------|
| 某某菜鸟**驿站**门口 | 驿站 | ✅ 整行标红 |
| 广州市**工商局**对面 | 工商局 | ✅ 整行标红 |
| 正常小区 3 栋 201 | 驿站 | ❌ 不标红 |
| 地址含**质检局**和**驿站** | 两者都在词库 | ✅ 整行标红 + 显示两标签 |

## 六、Win 环境执行指南（给你在 Win 上操作）

### 6.1 环境准备

```powershell
# 1. 安装 Python 3.11+（勾选 Add to PATH）
# 下载：https://www.python.org/downloads/windows/

# 2. 验证
python --version
pip --version

# 3. 创建工作目录
mkdir C:\qianniu-parser
cd C:\qianniu-parser

# 4. 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 5. 安装依赖（开发阶段）
pip install openpyxl requests pyinstaller
```

### 6.2 建议开发顺序

```
Step 1  解析模块
        - 手机号提取 regex
        - 紧凑格式拆分
        - 逗号倒序拆分
        - 单元测试（用文档内 2 条样本）

Step 2  关键词模块
        - keywords 列表 CRUD
        - 行文本扫描 + 命中词返回
        - 预览高亮逻辑

Step 3  xlsx 导出
        - 读取模板表头
        - 写入数据行
        - 命中行 A~I 全列 PatternFill 整行标红

Step 4  GUI 或 网页
        - 粘贴区 + 预览表 + 关键词设置 + 导出按钮

Step 5  晴红AI 对接（可选）
        - 仅服务端或带 token 调用
        - 规则失败时 fallback

Step 6  千牛导入实测
        - 导出 xlsx → 千牛批量发货 → 导入验证

Step 7  打包 EXE（可选）
        pyinstaller --onefile --windowed app.py
```

### 6.3 验收测试清单

- [ ] 样本 1 解析正确，保留 `[9196]`
- [ ] 样本 2 解析正确（倒序逗号）
- [ ] 批量 10 条混合格式解析
- [ ] 添加关键词「驿站」后，含驿站地址的行**整行**标红（预览所有列均为红色背景）
- [ ] 删除关键词后，整行标红消失
- [ ] 导出 xlsx 列名与模板一致
- [ ] 导出 xlsx 命中行 **A~I 全列**均为红色，Excel 中可见整行标红
- [ ] 千牛成功导入导出文件
- [ ] 解析失败行有明确提示，不丢数据
- [ ] （若接 AI）断网时规则解析仍可用

### 6.4 EXE 打包注意（Win 上执行）

```powershell
# 在 venv 激活状态下
pyinstaller --onefile --windowed --name "千牛地址解析助手" main.py

# 输出在 dist\千牛地址解析助手.exe
# 首次运行若被杀软拦截，需添加信任
```

**Mac 上无法完成的步骤（必须在 Win 做）：**

- PyInstaller 生成 `.exe`
- 双击 exe 运行测试
- 千牛客户端导入实测
- Windows Defender 误报验证
